## 📚 Cronograma da Aula 1

Nossa primeira aula cobre os conceitos fundamentais para entender o ecossistema de desenvolvimento de software, conectando a base teórica com a prática do mercado.

### Conteúdos Abordados:

1. **Git**
   * Versionamento de código essencial para o dia a dia.
   * Comandos principais (`init`, `add`, `commit`, `push`, `pull`, `branch`).
   * Boas práticas de fluxo de trabalho.

2. **APIs (Application Programming Interfaces)**
   * O que são e para que servem.
   * Conceito de requisições e respostas (Request/Response).
   * Verbos HTTP (GET, POST, PUT, DELETE) e Status Codes.

3. **Conexão entre Front-end e Back-end**
   * Como a interface se comunica com o servidor.
   * O ciclo de uma requisição web na prática.
   * Exemplo de consumo de API.

4. **POO (Programação Orientada a Objetos): O que é e como funciona na prática**
   * Pilares da POO (Classes, Objetos, Atributos e Métodos).
   * Aplicação prática no código do dia a dia.
   * Por que utilizamos esse paradigma.

5. **Introdução a Banco de Dados**
   * Conceitos básicos de modelagem (tabelas, linhas e colunas).
   * Relações entre dados.
   * Primeiras consultas (`SELECT`, `INSERT`, `WHERE`, etc.).
